# 语音配置

PC“语音”页上方为“语音输入环境”，下方为“语音快捷键设置”。环境区域显示单行路由和声卡状态，最后一行依次为输入电平、音频设备、刷新及系统输入设置。

## 设置

每组的启用、名称和类型同排。勾选启用展开热键，取消勾选只收起热键；名称和类型仍可编辑，隐藏值保留。长按类型显示“长按热键”，单击类型显示“开始热键”“结束热键”。

名称提示与以下热键说明各占一行：

> 热键：在手机端激活语音时触发，一般设置为PC端的语音输入法快捷键，留空则只传输音频。

| ID | 默认名称 | 类型 | 长按／开始热键 | 结束热键 | 启用 |
|---|---|---|---|---|---|
| voice-1 | 单击语音输入 | 单击 | RightCtrl+L | RightCtrl+L | 是 |
| voice-2 | 长按语音输入 | 长按 | RightAlt | 松手释放 | 是 |
| voice-3 | 自定义语音输入 | 长按 | 留空 | 松手结束 | 否 |

名称去除首尾空白后不能为空，ASCII 计 1、其他 Unicode 码点计 2，最多 16，等同八个汉字或十六个英文字符。尾音延迟适用于本 PC 全部组，默认 200 ms、范围 0–1000 ms。编辑后点击“保存并同步配置”。

豆包等输入法的热键需要与这里一致，左右修饰键分别记录。首次安装与音频路由见[安装说明](installation.md)，排查见[豆包热键](voice-hotkey.md)。

## 手机操作

- 长按为圆形，按住说话、松手结束；单击为方形，点击“开始”，再点“结束”。
- 顶部按 PC 顺序轮换启用组。仅一组时不能切换，全部关闭时显示“语音未启用”。
- 准备、传音、停止时冻结本轮名称、类型和热键，不能换组或换 PC；修改在下一轮生效。
- 每台 PC 单独记住组 ID，失效时选择首个启用组。控件位置保存在手机，见[多 PC](multi-pc.md)。
- 全键盘长按空格使用当前组并始终松手结束。方块启动的单击录音，第一次快捷键或触控板点击只结束录音。

## 兼容与验证

配置 schema 3、控制协议 v2。旧配置原样备份后迁移，既有名称和热键保留；0.3.12 起第三组默认关闭且各热键为空。未声明 `voice_profiles` 能力的旧 PC 使用原两组，旧手机使用所选类型第一组。

配置、录音快照和陈旧事件规则见[协议](../protocol/README.md)。原生页面测试 `TestVoiceProfileEditorUI` 与 Android 语音回归结果见[验证记录](verification.md)。
