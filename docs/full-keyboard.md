# 全键盘（2026-10-07）

顶部状态栏新增「全键盘」开关（与语音输入方式开关互斥显示在「连接」左侧）。打开后，下方的快捷键区与语音输入区整体隐藏，替换为一块全键盘，占屏幕下半部分（与原先两个区域合计的高度一致）；关闭后恢复原布局。

## 界面

| 行 | 内容（字母页） |
|---|---|
| 1 | Ctrl · Alt · Win · Esc · Tab · ← · ↑ · ↓ · → · 退格 |
| 2 | Q W E R T Y U I O P |
| 3 | Shift · A S D F G H J K L |
| 4 | 符号 · Z X C V B N M · PgUp · PgDn · 回车 · Space |

- 修饰键 Ctrl / Alt / Win、Shift 与「符号」都按点击切换：点亮表示已按下。
- Shift 是一次性修饰键：点一下变亮，下一个键抬起后自动复位，与实体键盘一致（Shift + d → `D`）。
- 「符号」切到符号页：数字行、`- = [ ] ; ' , . / \` 行，以及 `` ` `` Home End PgUp PgDn Del；Shift 在符号页给出上档字符（`!@#$%^&*()` 等）。
- 每个键按下即发送按下、松手即抬起；按住不放会按系统节奏自动重复（450 ms 后每 60 ms 一次）。
- 退出全键盘（或切换回普通布局）时释放所有按键与修饰键。

## 协议与接收端

新增两个消息：

```json
{"type":"key_down","revision":12,"text":"LeftShift+A"}
{"type":"key_up","revision":12,"text":"LeftShift+A"}
```

- `text` 是组合键文本，由 `input.ParseChord` 解析，`revision` 用于丢弃过期配置下的按键。
- 接收端在 `session` 中校验后转给 `internal/keyboard` 的 `KeyAsync`，最终调用引擎的 `PressKey` / `ReleaseKey`（内部就是 `Hold`，组合键文本作为持有键的键）。
- 因此按下与抬起是两条独立命令：按住手机上的键就等于按住 PC 上的键（Windows 会重复），组合键（修饰键 + 普通键）也按同一段文本释放，不会残留。
- 会话结束、心跳超时或断开时 `ReleaseAll()` 释放全部按键；配置版本不一致时返回 `config` 与错误，按键被丢弃。

## 实测（ONYX Tab8C / Android 11）

| 项目 | 结果 |
|---|---|
| 打开开关 | 快捷键区与语音区隐藏，键盘出现在下半部分；关闭后原样恢复 |
| 字母输入 | 手机点 A / S / D / F，记事本出现 `asdf` |
| Shift | 点亮 Shift 后点 D 输出大写 `D`，下一个键自动回到小写 |
| 长按 | 按住一个键 1.4 秒，PC 收到重复按键（记事本出现一串相同字符） |
| 修饰键 | Ctrl / Alt / Win 点击锁定，锁定后与普通键一起发送 |
| 单元测试 | `go test ./...` 含 `TestKeyboardKeyStatesAreForwarded`（转发与非法键拒绝） |

## 已知限制

- 键盘是精简布局（字母 + 符号 + 导航键），没有做中文输入；中文仍需用 PC 端输入法，或继续用语音输入。
- 布局按 4 行 × 10 列固定，屏幕特别小的设备上按键会变小（字号固定，未随宽度缩放）。
- 「符号」页与 Shift 的组合通过附加 `LeftShift` 实现，因此上档字符取决于 PC 的键盘布局（本机为中文/美式布局时结果与预期一致）。
