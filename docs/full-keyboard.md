# 全键盘（0.3.6，2026-10-08）

顶部状态栏新增「全键盘」开关（2026-10-07 起改为一个 Lucide `keyboard` 图标按钮：未激活 `#AAA`、激活 `#000`，位于连接图标左侧；语音输入方式的切换已移到语音区顶部，见 [Android 主界面](android-ui.md)）。打开后，下方的快捷键区与语音输入区整体隐藏，替换为一块全键盘；关闭后恢复原布局。**开关状态记在 Android 本地**（DataStore `keyboard_mode`），重开 App 沿用上次的状态。

0.3.1 起，两种模式共用同一个底部容器：内容高度为安全视口宽度的 60%，上下各留 1% 宽度的间距；状态栏高为宽度的 10%，触控板填满剩余高度。字号与图标同样随宽度变化，短窗口统一缩小纵向尺寸，详见 [Android 主界面](android-ui.md)。

## 界面

每格承载两个键位：下方是**主键位**（短按），上方是灰色的**副键位**（长按）；两者作为一组在键面居中，副键不再贴住顶部。空格的副键位提示为矢量麦克风图标。

| 行 | 副键位（长按） | 主键位（短按） |
|---|---|---|
| 1 | `1234567890` | `qwertyuiop` |
| 2 | `- / : ; ( ) ~ ' "` | `a s d f g h j k l` |
| 3 | `[Shift] @ - # & ? ! … [Backspace]` | `[Shift] z x c v b n m [Backspace]` |
| 4 | `[Ctrl]`（共用） `,` 语音输入 `[Shift+Enter]`（共用） `[Enter]`（共用） | `[Ctrl]` `.` `空格` `[Shift+Enter]` `[Enter]` |

第 4 行逐格：① `[Ctrl]` 短按一次左 Ctrl、长按持续按住，可搭配其他键（0.3.2 起替换 Alt）② `.`（长按＝`,`，只发一次）③ `空格` 短按一次空格、**长按＝长按语音输入** ④ `[Shift+Enter]` 短按一次、长按连续 ⑤ `[Enter]` 短按一次、长按连续。

逐格对应关系：

- 1 行：`1↔q`、`2↔w`、`3↔e`、`4↔r`、`5↔t`、`6↔y`、`7↔u`、`8↔i`、`9↔o`、`0↔p`。
- 2 行（主键位按 QWERTY 中行 `asdfghjkl` 排列，逐格对应）：`a↔-`、`s↔/`、`d↔:`、`f↔;`、`g↔(`、`h↔)`、`j↔~`、`k↔'`、`l↔"`。
- 3 行：`[Shift]` 与 `[Backspace]` 主副键位共用；`z↔@`、`x↔-`、`c↔#`、`v↔&`、`b↔?`、`n↔!`、`m↔…`。
- 4 行：`[Ctrl]` 短按一次、长按持续按住；`. ` 短按句点、长按 `,`（只发一次）；`空格` 短按一次空格、**长按等于长按语音输入**（按住说话，松手结束）；`[Shift+Enter]` 与 `[Enter]` 短按一次、长按连续。

### 键面样式

- 常规键（A–Z 字母、`.`、空格）白底；其余特殊键用 `#B6B9C2`，背景为 `#DCDDDF`。
- 圆角为视口宽度的 1.25%，浅色 0.5dp 细边加 1dp 阴影；按下时整键变蓝底白字。
- 副键位灰色、字号为视口宽度的 2.8%；主键位近黑色，单字符字号为宽度的 5%，多字符为 4%。主副标签整体居中、间距为宽度的 0.2%。空格保留文字，其上方使用 Lucide `mic-audio-lines` 矢量图标。
- Shift 使用 Lucide `arrow-big-up`，Enter 使用 `corner-down-left`，Backspace 使用 `delete`；Shift+Enter 并排显示上箭头与回车图标。四个键统一线宽 2、大小为视口宽度的 5%，替换字体符号并随按下状态变白。
- 手指按下即刻点亮（因为键值要等抬手或长按判定才发出），松手或切换界面时熄灭；Shift 单次 / 锁定、长按键按住、空格传音中同样点亮。

### 宽度（按屏幕宽度的百分比）

| 键 | 宽度 |
|---|---|
| 常规字母键、数字键所在按键、`.` | 8.9% |
| 横向键间隙、正常视口的行间距 | 1% |
| `[Shift]`、`[Backspace]`、`[Shift+Enter]` | 13.85% |
| `[Ctrl]`、`[Enter]` | 18.8% |
| `[空格]` | 33.65% |

左右各留 1%，1 / 3 / 4 行的总宽为 `键宽之和 + 间隙 = 98%`，加两侧留白为 100%（1 行 10×8.9+9×1、3 行 13.85+7×8.9+13.85+8×1、4 行 18.8+8.9+33.65+13.85+18.8+4×1）。2 行只有 9 键，总宽 88.1%，**整行居中**，左右边界各为视口宽度的 5.95%。

键盘四周各留 1% 视口宽度；上下直接复用底部原生容器的留白，键盘内部不重复添加。内容高度仍为 60% 宽度，减去三处行间距后四行均分；正常视口每行键面高约 14.25% 宽度，底部总高仍为 62%。受限窗口沿用纵向缩放，横向键宽和间距不缩小；其余快捷键与语音区的间距保持原样。

实现：`KeyboardGeometry` 集中计算四行的连续边界，再对累计坐标取整，不独立取整每个键宽或把余数塞给末键。普通键以十键首行推导，特殊键保留 1.5／2／3.5 个网格跨度。`KeyboardView` 使用 Compose Layout 按这些像素边界测量并放置键面；字号继续使用完整安全视口宽度。原生父容器与按指针 ID 分发事件的方式保持原样。

按键行为：

- **双键位键**（字母 / 数字 / 符号 / `.`）：**短按只发主键位一次，长按只发副键位一次**。长按判定（400 ms）由手势层的计时器完成，因此在判定为长按之前不会发出主键位，副键位也只发一次、不会因为按住而连续触发。（早期实现是按下即发主键位、长按再切副键位并保持，会先冒出一个短按并让副键位连发。）
- **Shift**：短按＝单次大写（点亮，用一次后自动复位）；长按＝锁定大写（一直生效），再短按一次解除锁定。锁定状态下按字母发 `LeftShift+字母`。
- **空格**：短按＝一次空格；长按＝长按语音输入，键值与语音区「长按语音输入」相同——达到阈值后**同时开始传音（mic 传输）并保持 PC 端长按热键**，松手结束。录音期间空格键整键变蓝，作为传音中的提示（键盘打开时语音区是隐藏的）。
- **退格 / Ctrl / 回车 / Shift+Enter**：短按＝一次完整按键；长按＝真正按住不放，由 Windows 连续触发（退格连续删、回车连续换行、Shift+Enter 连续换行、Ctrl 可配合其他键）。
- 键面点亮表示当前状态：手指按住、Shift 单次 / 锁定、长按键正在按住。
- 退出全键盘、断开连接或切回普通布局时释放所有按键与修饰键。
- 全键盘长按空格触发语音输入；关闭键盘后的语音区提供长按和单击两种模式。

## 协议与接收端

新增两个消息：

```json
{"type":"key_down","revision":12,"text":"LeftShift+A"}
{"type":"key_up","revision":12,"text":"LeftShift+A"}
```

- `text` 是组合键文本，由 `input.ParseChord` 解析，`revision` 用于丢弃过期配置下的按键。
- 接收端在 `session` 中校验后转给 `internal/keyboard` 的 `KeyAsync`，最终调用引擎的 `PressKey` / `ReleaseKey`（内部就是 `Hold`，组合键文本作为持有键的键）。
- 因此按下与抬起是两条独立命令：按住手机上的键就等于按住 PC 上的键（Windows 会重复），组合键（修饰键 + 普通键）也按同一段文本释放，不会残留。
- 会话结束、心跳超时、断开或单设备解绑时释放该会话持有的按键，保留其他设备的持有；停止接收或程序退出时 `ReleaseAll()` 全局释放。配置版本不一致时返回 `config` 与错误，按键被丢弃。

### 符号键走虚拟键盘

标点键（`Semicolon` / `Quote` / `Backquote` / `Slash` / `[` `]` `\`）此前不在 HID 映射表里，会被判为「虚拟键盘不支持」而整条组合键退到 SendInput——而豆包忽略 SendInput。现在这些按键在 `internal/hidkeyboard` 里补齐了 USB HID usage，2 / 3 行的 `- / : ; ( ) ~ ' " @ # & ? !` 都走虚拟键盘。

### `…` 只能按 Unicode 字符发送

Windows 键盘上没有 `…` 这个按键，虚拟键盘（HID）无法表示。按键表新增 `text` 字段与 `Ellipsis`（占位虚拟键码 `0xE000`）：注入时走 `KEYEVENTF_UNICODE`（`wVk=0`、`wScan=码点`），此时整条组合键自动走 SendInput。键盘发送方式选「虚拟键盘（HID）」时设置页会提示不支持 `Ellipsis`；「自动」与「软件按键」可用。

|---|---|
| 区域高度 | 关闭键盘：状态区 + 触控板 + 快捷键区 + 语音区占满 1404×1872；打开键盘：同一块下半区换成键盘，底部不再留空 |
| 键宽（截图逐像素量取，屏宽 1404） | 常规键 118 px＝8.4%、间隙 21 px＝1.5%、`[Shift]`/`[Backspace]` 188 px＝13.4%、`[alt]`/`[Enter]` 258 px＝18.4%、`[Shift+Enter]` 189 px＝13.5%、`[空格]` 469 px＝33.4%；1/3/4 行右边缘都在 x≈1390（两侧各留 10 px）；2 行 9 键居中排布、两侧各留 ≈72 px |

## 已知限制

- 键盘是精简布局（字母 + 符号 + 数字 + 少量功能键），没有做中文输入；中文仍需用 PC 端输入法，或继续用语音输入。PC 输入法处于中文模式时，字母会进入拼音组合，这与实体键盘一致。
- 布局固定 4 行，屏幕特别小的设备上按键和字号会随可用尺寸缩小。
- 上档字符（`@ # & ? !` 等）与 `:`、`"`、`~` 通过附加 `LeftShift` 发出，结果取决于 PC 的键盘布局；中文 / 美式布局下与预期一致。
- `…` 走 SendInput 的 Unicode 注入，目标窗口需要接受 `WM_CHAR`；表现为「按了没反应」时把键盘发送方式保持为「自动」。
- 双键位键的短按在**抬手**时才发出（必须先区分短按与长按），与实体键盘按下即出字略有差别。
- 键盘里没有单独的语音键：长按空格就是长按语音输入（同时开始传音并保持 PC 长按热键）；语音区仍在键盘关闭时可用。
