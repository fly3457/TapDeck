# Android 布局与交互

当前 Android **0.5.13 / code 38**。布局按安全视口宽度 `W` 和高度 `H` 计算，保留系统时间、电量和导航栏。

## 区域

| 区域 | 尺寸 |
|---|---|
| 顶部电脑栏 | `0.10W` |
| 底部内容 | `0.60W` |
| 底部上下留白 | 各 `0.01W`，总高 `0.62W` |
| 触控板 | `H − 0.72W` |
| 全键盘 | 四行 |
| 普通模式 | 快捷键与语音各占底部内容一半 |

当 `H < 0.82W`，纵向尺寸、字号和图标按 `H/(0.82W)` 缩小。快捷键 1–4 项一行、5–8 项两行；模式切换不移动触控板边界。电脑列表及设置弹窗可滚动。

全键盘键面、间隙和边界仍按原几何计算；0.3.18 将内部间隙纳入相邻键的触控范围，左右／上下平分。外层响应触摸，内层保留视觉尺寸，见[全键盘](full-keyboard.md)。

## 电脑与设置

顶部显示“电脑名称 ▾ · 状态”，连接后显示 RTT，长名称省略。右侧依次为电脑通知、视频模式、键盘模式与连接设置图标，各宽 `0.10W`；未连接或 PC 不支持视频时显示器图标为灰色，铃铛在有未读或已连接支持通知转发的 PC 时为黑色，并以红色角标显示未读数。电脑列表当前项置顶，其他项按添加顺序，支持添加、备注和单独忘记；录音准备、传音、停止期间禁止改变当前连接。

“连接与设置”显示版本与项目主页，最上面是配对区：连接网址、扫码入口，以及同一行的“管理电脑”和“连接”按钮；弹窗底部只有“关闭”；其下依次为按键震动、视频画质与后台接收电脑通知。扫码只填写网址，点击连接才请求 PC 授权；相机权限可拒绝。外部链接同样执行录音限制，拒绝的切换不排队。详见[多 PC 配对](multi-pc.md)。

未连接图标为橙色，每 3 秒弹跳三次（440 / 310 / 220 ms）；连接后为绿色并复位。提醒仅在前台且没有相关弹窗时播放。

## 样式与设备偏好

键盘与语音底色 `#DCDDDF`，普通键白色，特殊键 `#B6B9C2`，按下为蓝底白字。圆角 `0.0125W`、细边 0.5dp、阴影 1dp。主标签单字符 `0.05W`、多字符 `0.04W`，副标签 `0.028W`；字号补偿系统字体缩放，弹窗保留系统规则。

Lucide 矢量图标用于键盘、麦克风、修饰键及设置，不依赖 emoji。图标与许可证见[第三方声明](../THIRD_PARTY_NOTICES.md)。

触控板左上角调节灵敏度 `0.5×–3.0×`，默认 `1.0×`，只缩放鼠标移动。震动、灵敏度、键盘模式和控件位置保存在手机，不随电脑切换或忘记重置。API 29+ 使用 CLICK / HEAVY_CLICK，API 26–28 使用 15 / 30 ms 回退；按住、松手和重复不额外震动。设备实际反馈见[验证记录](verification.md)。

## 语音

模式按钮居中显示当前组名，顺序轮换已启用组；组 ID 按 PC 记忆。长按为圆形，单击为方形；单击空闲显示“开始”，准备、传音和停止显示“结束”，禁用显示“禁用”。

底部单行显示操作说明，录音时附电平百分比；顶边电平条按原百分比两倍显示，最大整行。控件可拖动，位置避开标题和底部提示。录音期间冻结当前组、类型和结束热键，见[语音配置](voice-profiles.md)。

## 视频模式

进入后普通布局隐藏，整屏为 PC 画面，系统栏改为沉浸式。普通模式锁定竖屏，视频模式跟随传感器旋转。画面按高度填满并居中，层级从下到上依次为：SurfaceView 画面、全屏手势层、底部半透明叠加键盘（快捷键盘或全键盘，互斥）、居中提示（打开中／出错时点击重试）、顶部工具栏（左侧退出与帧率；右侧电脑通知、快捷键盘、全键盘与最右的更多（两段式开关，展开后为恢复默认比例与体感控制）、语音悬浮球。全键盘叠加在底部，横屏时取屏幕短边宽度并压扁高度；快捷键盘为跟随悬浮球的小面板（竖屏 2 列、横屏 2 行）；悬浮球直径约 51dp；工具栏左侧连接信息固定宽度（窄屏竖屏时缩短，让出右侧四个图标），图标右对齐，见[视频模式](video-mode.md#快捷键盘与全键盘)。手势层为直接操作（单指平移画面、轻点左击、双击与双击拖拽、长按右击），见[视频模式手势](video-mode.md#手势)。

悬浮球直径 64dp，可拖动到距边缘 8dp 以内的任意位置，触摸判定半径为可见半径的 1.25 倍，未命中的触摸穿透给手势层。“连接与设置”增加视频画质单选（流畅／清晰／省流），保存在手机。详见[视频模式](video-mode.md)。

## 电脑通知

点击铃铛打开“电脑通知”列表（最近 100 条，按时间倒序，可清空），打开即标为已读并撤下已弹出的手机通知。App 在前台时，新通知在顶部以白色卡片横幅显示 3 秒，点击打开列表，不拦截其他触摸；视频模式中同样显示；视频模式右上角也有铃铛（最左侧），角标与点击行为相同。后台时以“电脑通知”渠道（高优先级）弹出手机通知，按 PC 分组，点击打开列表。

“连接与设置”增加“后台接收电脑通知”开关（默认开），以及在缺少权限时出现的“允许 TapDeck 发送通知”“允许后台运行（关闭电池优化）”按钮和机型自启动提示。首次连上支持通知转发的电脑且未豁免电池优化时，弹出一次“允许 TapDeck 后台运行”说明，确认后打开系统弹窗。开启时常驻一条最低优先级的“后台连接”通知。连接到旧版 PC 时显示升级提示。详见[电脑通知转发](notifications.md)。

## 构建与回归

官方 Windows 构建内嵌本次 APK，版本来自 `version.properties`。运行 `scripts/test-android-ui.ps1` 可在隔离模拟器重复五种配置：普通屏、小屏与 130% 字体、平板及受限高度，结束后恢复显示参数。

几何、手势、按键释放、配对入口及截图的实际结果统一见[验证记录](verification.md)，历史截图保留原版本路径。
