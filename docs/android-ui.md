# Android 0.3.6 主界面

参考微信输入法的浅灰键盘样式，按安全视口宽度计算尺寸。`W`、`H` 是扣除系统栏及刘海安全区后的应用视口宽、高；系统时间、电量和导航栏正常显示。

## 高度

| 区域 | 尺寸 |
|---|---|
| 顶部连接栏 | `0.10W` |
| 底部内容 | `0.60W` |
| 底部上下间距 | 各 `0.01W`，底部总高 `0.62W` |
| 全键盘 | 四行均分，行间距 `0.01W` |
| 非全键盘 | 快捷键、语音各占 `0.30W` |
| 触控板 | 剩余高度 `H − 0.72W` |

两种模式共用同一个底部容器，切换不移动触控板或底部边界。快捷键 1–4 项为一行，5–8 项为两行，第二行保留未使用的列。界面没有滚动容器。

当 `H < 0.82W` 时，纵向尺寸、字号和图标乘以 `H/(0.82W)`；按键宽度仍按视口宽度计算，触控板保留至少约 `0.10W × 缩放系数` 的高度。视口或安全区变化时重新测量；像素取整允许 1–2 px 差异。

## 样式

- 底部、快捷键、语音区统一浅灰 `#DCDDDF`；普通键白色，特殊键 `#B6B9C2`。
- 圆角半径为 `0.0125W`，浅色细边加轻微底部阴影。按下、Shift 激活、空格录音保持蓝底白字反馈。
- 主键位近黑 `#111216`，字号 `0.05W`；空格、Ctrl 等多字符键字号 `0.04W`。副键位灰色 `#929796`、字号 `0.028W`，比 0.3.1 放大约 27%。主副标签作为一组在键面居中，两者之间留 `0.002W` 间距，副键提示不再贴住上沿。
- 空格保留“空格”文字，麦克风使用 Lucide `mic-audio-lines` 矢量图标。
- Shift、Enter、Backspace 分别使用 Lucide `arrow-big-up`、`corner-down-left`、`delete`；Shift+Enter 并排组合前两个图标。图标统一 2 单位线宽、大小 `0.05W`，按下或 Shift 激活时变白，不使用 emoji 或字体符号。
- 顶部文字字号 `0.032W`，图标大小 `0.055W`，图标点击区域各宽 `0.10W`。保留电脑名、状态和已连接时的 RTT；长文字省略。
- 主界面尺寸和文字按宽度换算，补偿系统字体缩放；连接、配对弹窗保持系统字体规则。

0.3.2 将第四行首键从 Alt 改为左 Ctrl，可长按搭配其他键。0.3.6 普通键宽从 8.5% 改为 8.9%，横向间隙和左右外边距各为 1%；Shift / Backspace / Shift+Enter 为 13.85%，Ctrl / Enter 为 18.8%，空格为 33.65%，第二行继续居中。行间距为 1%，上下外边距复用底部容器已有的 1%，键盘内部不重复增加留白。按累计边界取整分配像素，第一、三、四行完整铺满；受限窗口只缩小纵向尺寸。其余键值、字体、配色及长短按语义保持原样，详见 [全键盘](full-keyboard.md)。触控板仍为黑底白字，0.3.3 将手势提示分为两行，增加双指缩放和三指窗口操作；标题和提示按宽度计算，高度受限时整组缩小并居中。具体行为见 [触控板手势](touchpad-gestures.md)。

## 应用图标

0.3.6 增加与 PC 相同风格的蓝底白色方块应用图标：蓝色为 `#175CD3`，不增加文字。普通兼容图标沿用 PC 的 32×32 网格和白色方块范围；自适应图标使用 108dp 图层及居中的 48dp 白色方块，API 33+ 提供同形的单色层。Manifest 设置 `android:icon` 与 `android:roundIcon`，用于桌面、应用列表和系统应用信息；外轮廓由系统圆形或圆角方形蒙版决定。图标资源均为原生矢量，依据 [Android 自适应图标规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。

## 连接入口

右侧 Lucide `plug` 图标点击后打开“连接与设备设置”，顶部可控制手机按键震动，下面保留连接电脑的网址输入。未连接为橙色 `#F59E0B`，每 3 秒向上跳动一次，幅度 `0.008W`，往返共 360 ms；连接成功变为绿色 `#22C55E` 并复位。

只有页面前台、连接、灵敏度或配对弹窗未打开、且未连接时播放提醒。连接成功、打开弹窗或切入后台后，立即停止并复位；再次需要提醒时重新等待 3 秒。

## 设备灵敏度与按键反馈

触控板左上角增加 Lucide `sliders-horizontal` 图标，点击打开本机灵敏度滑块和旁边的倍率数值。默认 `1.0×`，范围 `0.5×–3.0×`，步长 `0.1`，提供“恢复 1.0×”。未连接时也可以设置，调节立即生效；本机 DataStore 保存设置，重开、切换电脑或忘记配对不重置。

0.3.5 删除弹窗中的“0.5× 慢速”“3.0× 快速”和“立即生效，并保存在这台 Android 设备上”说明，保留滑块、当前倍率与恢复默认。

`1.0×` 采用此前 PC 灵敏度 `2` 的基准；Android 发送鼠标位移时再乘本机倍率。PC 移除可编辑灵敏度，旧配置及协议 v2 中的 `sensitivity` 固定为 `2`，保证旧客户端的基准速度。新 Android 不读取 PC 灵敏度来决定鼠标速度。双指滚动、缩放步进和手势识别阈值不受倍率影响。

图标放在原生触控板父容器的独立按钮中，与触控板表面分别按指针 ID 分发；点击图标取消待发轻点并释放拖拽，避免设置按钮生成鼠标操作。按钮随受限窗口缩小，仍位于触控板内部；其余区域尺寸不变。

快捷键、全键盘和语音触发控件共用振动服务。Android API 29 及以上直接发送设备调校的 `EFFECT_CLICK`，长按副键、Shift 锁定、按键保持及长按录音实际生效时发送 `EFFECT_HEAVY_CLICK` 再反馈一次；平台提供不支持效果的回退。API 26–28 使用 `View.performHapticFeedback(VIRTUAL_KEY/LONG_PRESS)` 并检查结果。松手、取消、自动重复和另一触摸区域的手指不产生额外反馈。语音模式按钮及顶部键盘模式切换也有轻震。

手机顶部连接图标 →“连接与设备设置”顶部的“按键震动反馈”默认开启，独立保存在当前设备；旁边提供“测试震动”与“手机系统振动设置”。系统触感关闭、强度设为关闭或无振动马达时给出提示，从系统设置返回后重新检测。PC“设置与状态”提供手机入口说明；PC 没有此设备本地开关。新增普通 `VIBRATE` 权限，无运行时授权弹窗。请求采用 `USAGE_TOUCH`（API 33+）或 `USAGE_ASSISTANCE_SONIFICATION`，遵循系统触感设置，不使用绕过设置的标志。测试成功提示表示已发送请求，实际马达效果仍由系统及硬件决定，依据 [Android 触感反馈说明](https://developer.android.com/develop/ui/views/haptics/haptic-feedback)。

## 语音区

模式按钮与按键采用相同的白底、圆角、细边和阴影。模式行高 `0.07W`，底部提示及电平区高 `0.045W`，录音控件直径 `0.12W`。可拖动范围预留模式行、底部提示和电平环，不会压住文字。

长按模式为圆形，按住 300 ms 开始、松手结束；单击模式为方形，轻点开始、再点结束。位置与模式仍保存到本地。单击录音时按快捷键只结束录音；长按空格继续触发长按语音输入。

## 构建与验收

Android 版本为 `0.3.6` / code `9`，包名与签名不变。正式发布通过 `scripts/build-windows.ps1 -OutputDirectory dist/0.3.6`，Windows EXE 嵌入本次构建 APK。

- JVM 测试覆盖正常、受限和极小视口，以及语音控件边界、连接提醒周期和取消。触控板状态机覆盖延迟单击、第二次按下／松手时机、拖拽、长按、取消、指针 ID、滚动方向、缩放锁定及三指一次触发。设备设置测试覆盖默认值、倍率边界、无效值、读取与调节竞态、写入顺序、关闭时保存及设备独立性。反馈策略覆盖本机开关实时变化、系统关闭、无马达、失败和旧系统回退结果，避免重复震动。
- 键盘几何测试覆盖按键宽度、间隙、四周留白、第二行居中及像素取整，短窗口与极小尺寸不得越界或重叠。
- Android 测试覆盖 1/4/5/8 项快捷键、两种模式边界、33 个键面实际宽度／间距、连接图标动画和设置入口，并生成截图；按键回归包含 Ctrl 短按、多指 Ctrl+C、Shift 单次大写、Enter、Shift+Enter、空格语音和退出清理。图标测试检查 PackageManager 读取结果、蓝白配色、48dp 前景范围和单色层，并输出系统／圆形／圆角方形／单色预览。
- 设备或模拟器验证结果记录在 [验证记录](verification.md)。实际手机的触感、字体显示和语音识别由真机验收确认。

在已启动的 Android 模拟器上运行 `powershell -File scripts/test-android-ui.ps1 -Serial emulator-5560` 可重复矩阵验收。脚本拒绝对实体设备修改显示参数，完成后恢复原始尺寸、密度和字体设置。日志与截图默认保存在 `dist/0.3.6/screenshots`。各配置验证灵敏度入口、滑块上下限、恢复默认、重新打开后的保存、反馈开关与测试按钮；正常、小屏 130% 字体及受限窗口重复验证触控板时序、双指缩放、三指滑动、语音区独立手指分发和按键反馈次数。正常配置额外检查振动服务中 `CLICK` / `HEAVY_CLICK` 的 TOUCH 完成记录，并验证关闭时不发送请求；该用例仅在模拟器临时调整触感设置，结束后恢复。

矩阵覆盖 1080×2400 / 字体 100%、720×1280 / 字体 130%、640×960 / 字体 130%、1404×1872 / 字体 100%，以及宽 1080 px、高度限制为 600 px 的应用视口。截图中的电脑连接、快捷键配置和交互回调来自测试模拟，不表示完成了真实电脑输入或音频链路验收。
