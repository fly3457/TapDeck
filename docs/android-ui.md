# Android 布局与交互

当前 Android **0.3.18 / code 21**。布局按安全视口宽度 `W` 和高度 `H` 计算，保留系统时间、电量和导航栏。

## 区域

| 区域 | 尺寸 |
|---|---|
| 顶部电脑栏 | `0.10W` |
| 底部内容 | `0.60W` |
| 底部上下留白 | 各 `0.01W`，总高 `0.62W` |
| 触控板 | `H − 0.72W` |
| 全键盘 | 四行 |
| 普通模式 | 快捷键与语音各占底部内容一半 |

当 `H < 0.82W`，纵向尺寸、字号和图标按 `H/(0.82W)` 缩小。快捷键 1–4 项一行、5–8 项两行；模式切换不移动触控板边界。电脑列表及设置弹窗可滚动。

全键盘键面、间隙和边界仍按原几何计算；0.3.18 将内部间隙纳入相邻键的触控范围，左右／上下平分。外层响应触摸，内层保留视觉尺寸，见[全键盘](full-keyboard.md)。

## 电脑与设置

顶部显示“电脑名称 ▾ · 状态”，连接后显示 RTT，长名称省略。右侧为键盘模式与连接设置图标。电脑列表当前项置顶，其他项按添加顺序，支持添加、备注和单独忘记；录音准备、传音、停止期间禁止改变当前连接。

“连接与设置”显示版本、项目主页、按键震动、管理电脑、连接网址和扫码入口。扫码只填写网址，点击连接才请求 PC 授权；相机权限可拒绝。外部链接同样执行录音限制，拒绝的切换不排队。详见[多 PC 配对](multi-pc.md)。

未连接图标为橙色，每 3 秒弹跳三次（440 / 310 / 220 ms）；连接后为绿色并复位。提醒仅在前台且没有相关弹窗时播放。

## 样式与设备偏好

键盘与语音底色 `#DCDDDF`，普通键白色，特殊键 `#B6B9C2`，按下为蓝底白字。圆角 `0.0125W`、细边 0.5dp、阴影 1dp。主标签单字符 `0.05W`、多字符 `0.04W`，副标签 `0.028W`；字号补偿系统字体缩放，弹窗保留系统规则。

Lucide 矢量图标用于键盘、麦克风、修饰键及设置，不依赖 emoji。图标与许可证见[第三方声明](../THIRD_PARTY_NOTICES.md)。

触控板左上角调节灵敏度 `0.5×–3.0×`，默认 `1.0×`，只缩放鼠标移动。震动、灵敏度、键盘模式和控件位置保存在手机，不随电脑切换或忘记重置。API 29+ 使用 CLICK / HEAVY_CLICK，API 26–28 使用 15 / 30 ms 回退；按住、松手和重复不额外震动。设备实际反馈见[验证记录](verification.md)。

## 语音

模式按钮居中显示当前组名，顺序轮换已启用组；组 ID 按 PC 记忆。长按为圆形，单击为方形；单击空闲显示“开始”，准备、传音和停止显示“结束”，禁用显示“禁用”。

底部单行显示操作说明，录音时附电平百分比；顶边电平条按原百分比两倍显示，最大整行。控件可拖动，位置避开标题和底部提示。录音期间冻结当前组、类型和结束热键，见[语音配置](voice-profiles.md)。

## 构建与回归

官方 Windows 构建内嵌本次 APK，版本来自 `version.properties`。运行 `scripts/test-android-ui.ps1` 可在隔离模拟器重复五种配置：普通屏、小屏与 130% 字体、平板及受限高度，结束后恢复显示参数。

几何、手势、按键释放、配对入口及截图的实际结果统一见[验证记录](verification.md)，历史截图保留原版本路径。
