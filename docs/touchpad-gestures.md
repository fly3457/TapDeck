# 触控板手势（0.3.6）

主界面继续采用黑底白字和原有区域尺寸。Android 按指针 ID 识别手势，坐标转换为 dp；触控板、键盘和语音区仍由原生父容器分别分发多指事件。

## 单击、双击及拖拽

首次轻点松手后等待 300 ms。若没有第二次相近位置的按下，发送一次左击；远处的第二次按下先结算前一次单击。

300 ms 内在相近位置第二次按下时，取消暂存单击，立即发送一次左键按下，此时电脑只收到单击按住。第二次快速松手、没有明显移动时，先释放左键，再补发一次点击；Windows 的双击只在此时生效。

第二次按住达到 300 ms，或移动超过 Android 触摸阈值，则松手只释放左键。快速松手还必须短于电脑实际双击时间减去 50 ms 的传输余量。阈值内的微小移动暂不发送，拖动达到阈值后结算缓冲位移。

触摸取消、断线、后台、键盘模式切换和增加手指都会取消待发单击并释放本次持有的左键。其他设备持有的鼠标按钮不会被释放。

## 双指

- 两指轻点右击；开始移动、缩放或加入第三指后，不再补发右击。
- 中心移动超过触摸阈值后锁定滚动。自然滚动开启时，上滑让内容上移，下滑让内容下移；关闭时反向。Windows 水平与垂直滚轮采用各自的符号。
- 指间距离变化超过 `max(8dp, 初始距离 × 4%)`，并超过中心移动的 1.2 倍时锁定缩放；张开放大、合拢缩小。距离每变化约 12% 发出一步 Ctrl＋滚轮。
- 滚动和缩放一旦锁定，直到全部松手前不会互相切换。缩放不受自然滚动设置影响，只适用于支持 Ctrl＋滚轮的软件。
- 抬起一指后，不把剩余手指重新解释成移动、滚动或左击。

## 三指

从第三指加入的位置计算中心位移。纵向位移至少 32dp，并达到横向的 1.5 倍时触发；一次触摸只执行一次。第三指加入立即停止两指操作，逐个抬指不产生其他手势。四指以上忽略，直到全部松开。

| 电脑状态 | 三指上滑 | 三指下滑 |
|---|---|---|
| 普通窗口 | Win＋Tab 打开任务视图 | Win＋D 显示桌面 |
| 已显示桌面 | Win＋D 恢复原窗口 | 保持桌面 |
| 任务视图 | 保持任务视图 | Esc 关闭并返回原窗口 |

电脑输入工作进程统一管理三个状态，各设备共享。Windows 前台窗口及关闭事件会校正状态；任务视图动画完成后才保留稳定窗口身份。Win＋D 的恢复不会打开此前已最小化的窗口，依据 [Windows 官方快捷键说明](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec)。

缩放遇到 Alt、Shift 或 Win 持有时拒绝；三指窗口操作遇到 Ctrl、Alt、Shift 或 Win 持有时拒绝。Android 提示松开相应修饰键后重试。缩放采用完整的一批 Ctrl 按下、滚轮、Ctrl 释放，只释放此次临时添加的 Ctrl；已有 Ctrl 和语音热键继续保持。

## 升级及验证

Android 为 `0.3.6` / code `9`，包名、签名及配对数据兼容；控制协议保持 v2。0.3.3 起电脑在 `ready` 中声明 `touchpad_zoom`、`three_finger` 和 `double_click_ms`，新消息使用可靠 WSS 及鼠标累计位移屏障。连接更早的电脑端时原有功能仍可使用，尝试新手势会提示升级。

0.3.4 把鼠标移动灵敏度改为各 Android 设备独立设置：点击触控板左上角图标调节 `0.5×–3.0×`，默认 `1.0×` 对应原 PC 灵敏度 `2`；PC 不再提供灵敏度输入框。倍率只应用于发送鼠标位移，不改变双击、拖拽和多指阈值，也不改变滚动或缩放速度。调节、关闭弹窗、重开 App、忘记配对后仍保留本机值，详见 [界面说明](android-ui.md)。

正式产物通过 `scripts/build-windows.ps1 -OutputDirectory dist/0.3.6` 生成；建议同时更新 EXE 和 APK。测试细节及实机待验项见 [验证记录](verification.md)。

Windows 原生验收通过 `scripts/test-windows-gestures.ps1` 重复执行：它新建隔离的 Edge 配置和测试网页／图片，短暂操作独立测试窗口、任务视图和桌面，结束后恢复窗口及鼠标位置。原生测试需显式设置 `TAPDECK_NATIVE_GESTURE_TEST=1`；浏览器测试另需隔离调试端口及图片路径，脚本会统一设置并恢复。普通构建不执行这些桌面动作。
