# 触控板手势

| 操作 | 效果 |
|---|---|
| 单指轻点 | 左击 |
| 双击 | 双击 |
| 双击后按住或移动 | 拖拽，松手释放 |
| 两指轻点 | 右击 |
| 两指移动 | 滚动 |
| 两指张开／合拢 | Ctrl＋滚轮缩放 |
| 三指上滑／下滑 | 任务视图与桌面操作，见下表 |

## 点击与拖拽

首次轻点等待 300 ms；相近位置第二次按下会取消待发单击并保持左键。第二次快速松手补发一次点击；按住达到 300 ms 或移动超过触摸阈值则进入拖拽，只在松手时释放。

快速松手还需短于 PC 双击时间减去 50 ms 的传输余量。触摸取消、断线、后台、模式或 PC 切换、增加手指都会取消待发动作并释放该会话的左键。

单击语音录音期间，触控板点击只结束录音，下一次点击才操作鼠标；长按语音可同时操作鼠标。

## 滚动、缩放与三指

滚动和缩放锁定后，直到全部松手前不会互相转换。抬起一指不会把剩余手指重新解释成其他操作；四指以上忽略。

两指中心移动超过触摸阈值触发滚动，方向由 PC 的自然滚动设置决定。指距变化超过 `max(8dp, 初始距离 × 4%)`，且超过中心位移的 1.2 倍时触发缩放；约每变化 12% 发出一步，适用于支持 Ctrl＋滚轮的软件。

三指纵向位移至少 32dp，且达到横向的 1.5 倍时触发，一次触摸只执行一次：

| 电脑状态 | 三指上滑 | 三指下滑 |
|---|---|---|
| 普通窗口 | Win＋Tab 打开任务视图 | Win＋D 显示桌面 |
| 已显示桌面 | Win＋D 恢复原窗口 | 保持桌面 |
| 任务视图 | 保持任务视图 | Esc 返回原窗口 |

PC 根据前台窗口校正共享状态。Win＋D 不会恢复原本已经最小化的窗口，见 [Windows 快捷键说明](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec)。

缩放遇到 Alt／Shift／Win 持有时提示松开；三指操作遇到任意修饰键持有时提示松开。已有 Ctrl 在缩放结束后仍保持，不影响其他会话的按键。

## 设置与验证

触控板左上角可调本机灵敏度 `0.5×–3.0×`，默认 `1.0×`。它只改变鼠标移动，不改变滚动、缩放或手势阈值，重启和忘记配对后仍保留。

协议保持 v2。PC 从 0.3.3 起声明 `touchpad_zoom`、`three_finger`、`double_click_ms`；更早版本缺少能力时，手机会提示升级。

Android 回归用 `scripts/test-android-ui.ps1`。Windows 原生验收用 `scripts/test-windows-gestures.ps1`，会创建独立 Edge 配置和测试窗口，操作任务视图与桌面，并在结束时恢复窗口和鼠标位置。普通构建不执行这些桌面动作。

当前结果和历史实机范围见[验证记录](verification.md)。
