# 2026-11-04 配对地址修复与“连接与设置”排序

问题：PC 网址显示 WSL 虚拟网卡地址 192.168.160.1，手机访问不到；证书只含接收端启动时的 IP（192.168.31.226），电脑换到 192.168.1.11 后，手机即使填对地址也因 TLS 地址校验失败而连不上。

- [x] 复现定位：pair-info 返回 192.168.160.1；证书 SAN 无 192.168.1.11；手机可 ping、可连 192.168.1.11:41080
- [x] 接收端：地址排序（真实网卡 > 私有局域网 > 默认路由），虚拟网卡按名称与 MAC 识别
- [x] 接收端：配对网址、pair-info、APK 链接实时计算，网络变化后自动更新
- [x] 接收端：TLS 改用 GetCertificate，出现新地址时用同一私钥补签（指纹不变）
- [x] Android：只按证书指纹认证，不再校验证书中的 IP（兼容旧接收端）
- [x] Android：“连接与设置”配对区移到最上面
- [x] 单元测试：虚拟网卡识别、排序、私有地址、证书补签保持指纹
