# 2026-11-04 通知转发：Windows 系统通知 → 手机 ＋ Agent 完成提醒

计划：Windows 接收端用公开 WinRT `UserNotificationListener` 读取全部系统通知并转发到手机；Agent（Claude Code / Codex）通过 hook 弹 Windows Toast，经同一通路同步；手机后台由前台服务保持连接并弹系统通知。
