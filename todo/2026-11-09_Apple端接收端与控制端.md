# Apple 端：macOS 接收端 + iPhone 控制端

日期：2026-11-09

## 需求

- 新增 macOS 接收端（被控端）：目标机 MacBook Pro 16" 2021（Apple M1 Pro），macOS Sonoma 14.4.1。
- 新增 iPhone 控制端：最低 iOS 15（覆盖 iPhone 13 及以上机型）。
- macOS 只做接收端，不做控制端。
- 首版功能与现有 Windows / Android 对齐。
- 当前只能在 Windows 上写代码，无法编译 Swift / macOS cgo；后续由用户在 Mac 上编译或开 SSH。

## 已确认的平台限制

- macOS 没有公开接口读取其他应用的系统通知：Mac 端只转发 Claude Code / Codex 等 Agent 提醒（hook 直接投递给接收端），不转发系统通知。
- macOS 语音传音需要用户自行安装 BlackHole 2ch 虚拟声卡（对应 Windows 的 VB-CABLE）。
- iOS 切到后台约 30 秒后会被挂起，后台无法长期保持连接：电脑通知只在前台或刚切后台时收到。
- iOS 安装包需要 Apple ID 签名（Xcode 直装或 TestFlight），不能像 APK 一样扫码下载安装，接收端不内嵌 iOS 包。

## 架构决定

- Mac 接收端复用现有 Go 接收端（`windows/` 模块，模块名 `tapdeck`）：服务端、协议、配对、加密、视频流管理全部共用，只补 darwin 平台实现。
  - 输入：CGEvent（鼠标相对/绝对移动、按键、滚轮、双击计数）。
  - 视频：ScreenCaptureKit 截屏 + VideoToolbox H.264 硬件编码，实现现有 `video.Launcher` 接口，不内嵌 ffmpeg。
  - 电脑声音：ScreenCaptureKit 系统音频采集，实现 `Loopback`。
  - 手机传音：CoreAudio HAL 输出到 BlackHole 2ch，复用 Windows 的抖动缓冲逻辑（抽成跨平台代码）。
  - 证书私钥：保存在 `~/Library/Application Support/TapDeck`，权限 0600。
  - 界面：菜单栏图标 + WKWebView 设置窗口（本机 HTML 界面）+ 原生配对确认弹窗，cgo Objective-C 实现。
- iPhone 控制端：SwiftUI + UIKit，XcodeGen 生成工程；协议与 Android 逐条对齐。
- 版本：Mac 接收端与 Windows 接收端同一份 Go 源码，共用 `receiver.version`；新增 `controller.ios.version` 与 `controller.ios.build`。
