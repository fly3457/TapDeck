# 2026-11-08 空闲黑屏屏保

需求：USB 常连的索尼 Xperia 1 V（OLED）在 TapDeck 常亮界面上长时间不动容易烧屏。希望空闲时屏幕变黑但不锁屏，随时可用。

方案：设置里新增“空闲黑屏屏保”开关（默认关闭）和空闲时长选择；TapDeck 在前台、普通模式、没有弹窗和录音时，超过设定时长无触碰就盖一层全黑并隐藏系统栏，显示一个缓慢移动、碰到屏幕边缘回弹的时钟；屏幕保持常亮不锁屏；手一碰就解除，这一下不传给下面的按键和触控板。

- [x] 屏保视图：黑底、时钟与日期，缓慢移动并在边缘回弹（约 30fps 刷新）
- [x] 空闲控制器：计时、触碰/按键解除、吞掉唤醒那一下、暂停条件（视频模式、语音输入、弹窗、离开前台）
- [x] 本机偏好：开关（默认关）与时长（默认 5 分钟）保存在手机
- [x] 设置页：开关、时长选择、“预览屏保”
- [x] 单元测试：回弹轨迹与控制器状态
