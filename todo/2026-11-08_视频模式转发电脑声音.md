# 2026-11-08 视频模式：把电脑声音转发到手机

需求：视频模式下手机能看到电脑画面，但听不到电脑播放的声音；用户在另一个房间用手机管理电脑时需要听到。

方案：电脑用 WASAPI 回环采集默认播放设备的输出（48 kHz 立体声 16 位 PCM，每 10 ms 一包），随视频连接以二进制类型 4 发给手机；手机用 AudioTrack 低延迟模式播放并控制缓冲；“更多”菜单最下方加扬声器开关；手机语音输入时自动静音防回声。

- [x] 电脑端：audio.Loopback 回环采集默认播放设备，默认设备变化时自动切换；默认设备是 VB-CABLE 时不采集（避免把手机麦克风声音传回手机）
- [x] 电脑端：video_start 的 audio 字段、video_audio 开关消息、ready.features 声明 video_audio、/video 连接发送类型 4
- [x] 手机端：解析类型 4，PcAudioPlayer 低延迟播放、积压超限丢弃、语音输入时静音
- [x] 手机端：“更多”菜单扬声器开关（Lucide volume-2 / volume-x），状态保存在本机
- [x] 单元测试：Go 音频消息与开关；Android 解析与缓冲策略
- [x] 协议、视频模式文档，第三方声明
- [x] 升版双端（0.5.15 / code 40），官方构建
- [x] 实机验证：努比亚无线安装，AudioTrack 活跃且走低延迟通道，开关关闭/打开生效
- [x] 修正：竖屏连接信息宽度放宽到 220dp，不再截断“延迟XXms”
